# Jiyad-3031-mirox-internship 
Project Description

AI Adversarial Vision Benchmark is a cybersecurity and AI project that evaluates the impact of adversarial attacks on image classification models. The application demonstrates how attacks such as noise injection and steganography can reduce AI prediction accuracy and how defense techniques can improve the model’s robustness. The project includes an interactive Streamlit web interface for uploading images, running attack and defense tests, and generating benchmark results. It also provides visual performance metrics and reports to compare baseline, attacked, and defended model accuracy.

Key Features

* AI image classification
* Noise attack simulation
* Steganography attack simulation
* Defense filtering techniques
* Benchmark result generation
* Interactive Streamlit dashboard
* Excel report with charts and metrics

Technologies Used

* Python
* Streamlit
* PyTorch
* Hugging Face Transformers
* Pillow (PIL)
* NumPy
* Pandas
* OpenPyXL
